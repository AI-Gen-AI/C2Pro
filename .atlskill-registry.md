## Key Conventions

- TDD: RED → GREEN → REFACTOR
- Domain: pure Python, no SQLAlchemy imports
- Adapters: FastAPI, SQLAlchemy, Celery
- Tenant isolation: filter by tenant_id on all queries
- Test Suite IDs: required in all test/implementation docstrings
