# C2Pro Memory Protocol

Before saving a new memory:
1. Search Engram for related memories.
2. Reuse or update existing topic_key when the topic already exists.
3. Only save durable knowledge.

Save memory only for:
- architecture decisions
- important technical decisions
- difficult bug fixes
- critical configuration
- reusable implementation patterns
- meaningful discoveries
- stable project preferences

Do not save memory for:
- trivial edits
- file renames
- test runs
- incomplete experiments
- temporary debugging notes
- obvious one-line fixes

Use this structure:
- What
- Why
- Where
- Learned

Preferred topic_key families:
- architecture/*
- decision/*
- bug/*
- config/*
- pattern/*
- discovery/*
