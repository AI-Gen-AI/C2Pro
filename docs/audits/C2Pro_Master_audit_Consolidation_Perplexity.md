### Project Intelligence

### RC-2: Wrong Unit of Work in the Graph

## Phase 9 — Master Consolidated Roadmap

### Next 30 Days — Stabilize & Prove the Foundation

1. **Fix the runtime bug.** Repair `coherence_scorer_node` kwargs mismatch. This is a broken core path — ship nothing else while it remains broken.
2. **Fix silent failures.** Introduce `NodeResult{status, data, error}`. Surface degradation as a visible signal in the UI. A 0-risk extraction that is actually a failed extractor must be distinguishable.
3. **Disable `low_budget_mode` as default** in the project-level analysis path. The headline feature must run at full capability.
4. **Introduce `ProjectSnapshot` model.** Append-only table: health vector, scores, open risks, totals, timestamp. Even if health dimensions are incomplete, the temporal substrate must exist now — everything else builds on it.
5. **Begin semantic diff v0.** Clause-level: added / removed / modified between document revisions. This is the feature that makes C2Pro indispensable.
6. **Repo hygiene.** Remove stray scripts, committed artifacts, `__pycache__`. Do it before any enterprise demo.
7. **Harden Excel parser.** Header detection replaces hardcoded row/column assumptions.

### Next 90 Days — Build the Product Core

1. **Project Health Engine v0.1.** Using existing data: Risk health + Contract health + Documentation health + Governance health. Four dimensions with confidence scores and thresholds. No fabricated greens (apply ADR-009 discipline).
2. **Two-tier graph architecture.** DocumentGraph (N1–N9, typed `DocumentArtifact` outputs) + ProjectGraph (synthesis, cross-document coherence, health, delta, alert assembly). The missing graph.
3. **Alert correlation engine.** Group related alerts into one actionable decision object with: severity, financial impact estimate, affected WBS/clause/timeline nodes, recommended action, owner, SLA, escalation path.
4. **Persona HITL queues.** Contract Manager sees risk extractions; Planner sees WBS deviations; Executive sees health summary requiring approval.
5. **Change Order workflow v0.1.** Request → review → approve → link to WBS/budget. First real daily workflow beyond document upload.
6. **Replace TypedDict aliases.** `Risk`, `WbsActivity`, `BomItem`, `Citation` as Pydantic models inside the graph state channels.

### Next 6 Months — Become a Product

1. **Schedule baseline + EVM engine.** SPI proxy, CPI proxy, earned duration vs. planned, critical path slack. Enables Schedule Health + Cost Health dimensions in the Health Engine.
2. **RFI and submittal tracking.** Submit → assign → respond → close. With AI-drafted response suggestions routed through HITL.
3. **Portfolio / PMO dashboard.** Multi-project health view with red/amber/green matrix. This is the enterprise buyer's first view.
4. **External integrations v0.1.** Passive SharePoint/OneDrive ingestion (document polling). P6 XML import for schedule baseline. These unlock the "AI overlay" positioning.
5. **Full cross-document Coherence Score.** The real one: 6 categories across contract + schedule + budget, running with the LLM semantic and RAG similarity nodes in the hot path.
6. **Risk register with lifecycle.** Identify → assess → mitigate → monitor, with AI suggestions and HITL validation.

### Next 12 Months — Enterprise & Intelligence

1. **Predictive forecasting.** ML-based project completion date and final cost prediction, built on 6+ months of `ProjectSnapshot` history.
2. **Active learning from HITL corrections.** Human modifications generate few-shot examples; pushed to vector store for prompt augmentation.
3. **Cross-project analytics.** Benchmarking, pattern detection, PMO portfolio intelligence.
4. **Enterprise hardening.** SSO, granular RBAC, compliance evidence exports, audit log completeness, SLA guarantees.
