## Work packages / acceptance

**W311-A — Opt-in foundations:** tracked env template both tracing flags OFF, `LangSmithConfig` default OFF, **central default-deny LangChain/LangGraph exporter policy for analysis, Coherence async/stream, WBS, BOM, ProjectGraph, HITL resume AND root-level QA swarm/code-auditor/auto-fixer/deployment-agent scripts executed under GitHub Actions, plus every independent Python process** even with ambient flag; synthetic unit/integration canaries for each parent/child runnable path and a source-wide inventory contract for future callsites. **No production exporter enablement.**

**W311-B — SDK/feedback, evaluation-update and legacy retrieval egress:** allowlisted non-content span contract; block raw `system`, `messages`, completion, error, legacy retrieval `query`, evaluation `expected`/`actual` nested metadata through `update_run`, and free-form feedback; require synthetic `CANARY_EVAL_EXPECTED_SECRET` / `CANARY_EVAL_ACTUAL_SECRET` zero-export tests even if `start_run` passes, and enforce registered route auth/tenant trace ownership, plus owned-trace comment/key canary. Preserve local cost/tokens/latency. Fail closed for external output and fail open for lawful business execution when collector unavailable.

**W311-C — Direct tools and CI:** evaluation workflow default OFF, manual RunTree script's `RunTree.post()` **and** LangGraph `app.ainvoke` both default no-network with parent/child synthetic canaries, dataset manager default deny for upload/create/delete/update/sync-baseline, legacy Hub publisher default-dry-run and resolver default-local. Require immutable manifest, classification and per-operation authorization before optional future external write/read.

**W311-D — Prompt governance / qualifications:** immutable `prompt_id`, version, SHA-256, provenance, dataset+eval evidence, owner/HITL approval, reversible promotion, no mutable remote production labels. Use identical privacy-filtered synthetic traces to evaluate LangSmith/other candidates; compare metrics/privacy/licensing/operational cost without live customer data.

**Exit gate for this inventory:** file-level evidence, clearly distinguished risks, exact-head review and CI for this doc. **Actual Wave 3.11 security completion is NOT granted by this inventory.** Implement W311-A/B/C via separate scoped work envelopes, RED→GREEN tests, independent security/challenger review and exact-head CI, then separately qualify provider activation.
