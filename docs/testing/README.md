# Testing Documentation

This section groups the main test planning, inventory, registry, and reporting documents.

## Governance

- Active execution status is canonical in `.c2pro/control/` and assigned work envelopes.
- Product lifecycle/readiness state is canonical in the product-control YAML/Markdown pair.
- Testing documents in this folder provide test scope, suite detail and evidence; they do not own current task/programme state.
- `C2PRO_MASTER_BACKLOG.md` and category backlogs are read-only legacy/cold references.
